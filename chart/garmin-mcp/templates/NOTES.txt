Reminder: if your Garmin account uses MFA, the first login cannot run inside a
pod. Pre-authenticate locally with `garmin-mcp-auth`, then install with
  --set-file garmin.tokens.json=$HOME/.garminconnect/garmin_tokens.json
(or put that JSON under the GARMINTOKENS key of garmin.existingSecret).
